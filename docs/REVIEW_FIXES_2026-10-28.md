# 2026-10-28 复核修复与验收

本次修复复核发现的三项问题，上传源码与验收资料，不创建正式 tag 或 Release。

## 修复结果

1. 快速添加：后端分别记录编辑是否打开与临时高度。正常高度已超过 320 时，编辑期间也禁止自动收纳；关闭编辑后恢复收纳。前端草稿由 WidgetApp 持有，切换模式和关闭重开均保留标题与日期，成功创建任务后清空。草稿仅在当前进程内保留，不写入任务数据库，不承诺退出后恢复。
2. 统计：逾期统计与倒计时使用同一共享时钟，跨过截止秒数时更新，不再等待下一分钟；排序仅在任务变化时重算。
3. 收起条：展开时沿用当前左上角与宽度，恢复正常高度，再按工作区限制位置，避免跳回收起前的横坐标。
