# PRD — 产品需求说明

产品：CheckIt（v0.1.0）
定位：轻量、美观、可靠的玻璃态桌面任务管理和截止时间提醒工具
口号：Check it. Get it done.

## 1. 目标用户

大学生、研究生、教师、职场人士、自由职业者，以及所有需要管理任务与截止日期的人群。

## 2. 核心问题

用户的任务（作业 / 报告 / 比赛 / 论文 / 会议 / 考试 / 项目）分散且带有明确截止时间。
传统日历以"日期"为中心，信息密度低；CheckIt 以 **Deadline 为中心**：
快速记录 → 桌面常驻倒计时 → 关键节点多级提醒。

## 3. 产品原则

1. Desktop First：真正的 Windows 原生桌面体验
2. Local First：核心功能完全离线
3. Lightweight：低内存 / CPU 占用，适合长期后台
4. Reliable：数据与提醒可靠（幂等、可恢复）
5. Beautiful：高质量玻璃拟态（Premium Minimalism + Modern Glassmorphism）
6. Non-intrusive：不打扰正常工作
7. Open Source：适合 GitHub 开源与二次开发
8. Maintainable：模块化、可测试架构

## 4. 功能需求

### 4.1 桌面悬浮小组件（主界面）

- 默认 340 × 440，无边框、圆角、半透明、背景模糊（原生 Acrylic 优先，CSS 降级）
- 可拖动 / 可缩放 / 置顶切换；位置与大小持久化；多显示器恢复时钳制到可见区域
- 可收起为标题栏细条；可随时展开
- 布局：标题栏（Logo / 日期 / 置顶 / 收起 / 菜单 / 快速添加）→ 状态概览（待办 / 今日到期 / 已逾期）→ 任务列表（按截止时间升序，前 N 条）→ 底部（今日进度条 + 全部任务入口）

### 4.2 完整任务管理窗口

- 视图：全部 / 今日 / 未来 7 天 / 已逾期 / 已完成 / 分类 / 分类管理 / 设置
- 工具栏：搜索、分类筛选、排序（截止时间升降 / 优先级 / 创建时间）
- 任务表单：标题（必填）、描述、分类、优先级、截止时间（日期+时分）、多选提醒
- 分类管理：新建 / 重命名 / 换色 / 删除（删除不删任务，任务变未分类）

### 4.3 任务

- 字段：id / title / description / category_id / priority / status / due_at / created_at / updated_at / completed_at / reminders
- 状态：Pending / Completed；Overdue 为运行时派生（不落库）
- 优先级与时间紧急度为两个独立维度

### 4.4 倒计时

- > 24h：X天 X小时；< 24h：X小时 X分钟；< 1h：X分钟 X秒；逾期：逾期 X…
- 颜色：正常 / 琥珀（<24h）/ 红（<1h 及逾期）/ 完成绿色；阈值集中配置
- 每次以真实 now 计算差值；全应用共享 1Hz 时钟，禁止每任务独立定时器

### 4.5 提醒

- 预设：1 天 / 3 小时 / 1 小时 / 30 分钟 / 10 分钟 / 截止时；可组合、可自定义（分钟粒度）
- Rust 后台调度：绝对时间判断、与 SQLite 同步、幂等去重（reminder_events 唯一约束）
- 15 分钟补发宽限：错过的提醒在宽限内照常通知，超宽限静默标记（防唤醒洪泛）
- 重启后自动恢复未触发提醒；完成任务停止后续提醒
- 应用退出 / 关机期间的提醒不保证送达（如实告知，不做虚假承诺）

### 4.6 托盘与后台

- 菜单：打开 CheckIt / 添加任务 / 任务管理 / 窗口置顶 / 设置 / 退出
- 关闭悬浮窗默认隐藏到托盘（设置可改为退出）
- 开机启动：默认关闭，用户显式开启后写入

### 4.7 设置

主题（深/浅/跟随系统）、玻璃开关与透明度、置顶、关闭到托盘、通知开关、默认提醒、悬浮窗显示数量、开机启动、数据库位置展示。全部持久化。

## 5. 非功能需求

- 启动 < 2s；空闲 CPU ≈ 0；共享定时器；写库操作即时
- 中英文排版良好；全部界面文本简体中文，文本集中于 i18n/zh.ts 便于国际化
- 所有数据库写入系统应用数据目录

## 6. v0.1.0 明确不做的

账号 / 云同步 / 协作 / 移动端 / AI 识别 / 聊天软件读取 / 浏览器扩展 / 支付 / 日历同步。
周期任务、导入导出、自然语言录入 → 见 ROADMAP。
