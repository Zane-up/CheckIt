# ROADMAP — 开发路线

## v0.1.0（当前）— 核心闭环

- [x] Phase 1 项目初始化（Tauri 2 + React 19 + TS strict + Tailwind 4）
- [x] Phase 2 悬浮小组件窗口（无边框/玻璃态/拖动/置顶/几何记忆/收起）
- [x] Phase 3 SQLite 持久化 + 任务/分类 CRUD + 多窗口同步
- [x] Phase 4 动态倒计时（自适应粒度/紧急度/逾期，跨天跨年闰年测试）
- [x] Phase 5 提醒调度器 + 原生通知 + 幂等去重 + 托盘 + 开机启动
- [x] Phase 6 主题/设置持久化/空状态/长标题截断/键盘操作
- [x] Phase 7 文档/LICENSE/CHANGELOG/CI/NSIS 安装包
